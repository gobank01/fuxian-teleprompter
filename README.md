# Fuxian Teleprompter 📖

Teleprompter สำหรับอ่านสคริปต์ตอน **Live ขายของ** — เว็บล้วน ไฟล์เดียว ไม่ต้องติดตั้งอะไร

🌐 **ใช้เลย:** https://fuxian-teleprompter.vercel.app (แนะนำ Chrome)

## ฟีเจอร์

- **อ่านไปเรื่อยๆ** — กด "เริ่มอ่าน" แล้วสคริปต์เลื่อนเอง ปรับความเร็ว/ขนาดตัวอักษรได้ระหว่างอ่าน
- **จำตำแหน่ง** — ออกแล้วกลับมาอ่านต่อจากเดิมได้ ไม่ต้องหาที่ค้าง
- **คั่นช่วงสินค้า** — ขึ้นบรรทัดด้วย `# ชื่อสินค้า` แล้วกดข้ามช่วงได้ (ปุ่ม ⏮⏭ หรือลูกศรซ้ายขวา)
- **โหมดตามเสียง** 🎙 — สคริปต์เลื่อนตามที่พูดจริง (ตัดคำไทยด้วย `Intl.Segmenter` + Web Speech API `th-TH`) พูดนอกสคริปต์ได้เดี๋ยวตามทัน แตะคำเพื่อย้ายตำแหน่ง
- **หน้าต่างลอย** 🔲 — Document Picture-in-Picture ลอยทับแอป Live / OBS ได้
- **รีโมทมือถือ** 📱 — เปิด `remote.html` บนมือถือ ใส่รหัส 6 หลัก คุมเล่น/พัก/เร็ว/ช้า/ข้ามช่วงข้ามเครื่องผ่าน WebRTC (PeerJS) มี auto-reconnect
- **โหมดกระจก** 🪞 สำหรับ beam-splitter rig · กันจอดับ (Wake Lock) · เก็บสคริปต์หลายชุดใน localStorage

## คีย์ลัด (ระหว่างอ่าน)

| คีย์ | ทำอะไร |
|---|---|
| `Space` | เล่น / พัก |
| `↑` `↓` | เร็วขึ้น / ช้าลง |
| `←` `→` | ช่วงก่อน / ช่วงถัดไป |
| `Esc` | ออก (จำตำแหน่งไว้) |

## รันเอง

ไฟล์ static ล้วน — เปิด `index.html` ตรงๆ หรือ host ที่ไหนก็ได้:

```bash
python3 -m http.server 8231
```

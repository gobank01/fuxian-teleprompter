# Fuxian Teleprompter 📖

**เว็บอ่านสคริปต์ฟรี ภาษาไทย ใช้ได้กับไลฟ์ขายของ คลิปวิดีโอ การสอน และการนำเสนอ** พิมพ์หรือนำเข้าสคริปต์ของคุณ แล้วให้ข้อความเลื่อนตามความเร็วที่อ่านสบาย ไม่ต้องสมัครสมาชิก

มีสคริปต์ตัวอย่าง **Fuxian Multi-Oil LIVE 100 ท่อน** ให้ลองทันที และสร้างสคริปต์เรื่องอื่นได้ตามต้องการ ตัวแอปเป็นเว็บ static ไม่มี backend หรือขั้นตอน build แจกซอร์สภายใต้ [MIT License](LICENSE)

## เริ่มใช้ใน 1 นาที

1. เปิดเว็บ เลือกสคริปต์ตัวอย่าง หรือสร้างสคริปต์ใหม่แล้ววางข้อความของคุณ
2. เปิดตั้งค่าการอ่านเพื่อเลือกการจัดข้อความ และปรับความเร็ว/ขนาดตัวอักษรจากแถบด้านล่างหลังเริ่มอ่าน
3. ถ้าเนื้อหาต้องอ่านเรียงตามลำดับ ให้ **ปิดการสุ่มท่อน** ก่อนเริ่ม
4. กด **▶ เริ่มอ่าน** แล้วอ่านหลังนับถอยหลัง ใช้ `Space` เพื่อพัก และ `Esc` เพื่อกลับไปแก้ไข
5. กดสำรองทั้งหมดเป็น `.json` เป็นระยะ เพื่อเก็บสคริปต์ไว้นอกเบราว์เซอร์

ค่าเริ่มต้นคือ **สุ่มท่อนเปิด · วนซ้ำเปิด · นับถอยหลัง 3 วินาที · จัดกึ่งกลาง** เพราะเริ่มพัฒนาจากการอ่านสคริปต์ไลฟ์เป็นท่อนอิสระ ขนาดตัวอักษรเริ่มต้นคือ 34 px บนมือถือและ 52 px บนจอใหญ่ เปลี่ยนได้ในหน้าตั้งค่าการอ่าน: ปิดการวนซ้ำเพื่อหยุดเมื่อจบ เลือกนับถอยหลัง 0 / 3 / 5 วินาที และจัดข้อความชิดซ้ายหรือกึ่งกลาง

## ทำอะไรได้บ้าง

- สร้าง แก้ไข ทำสำเนา และเก็บหลายสคริปต์ พร้อมจำนวนอักขระ จำนวนท่อน และสถานะบันทึก
- นำเข้า `.txt`, `.md` หรือไฟล์สำรอง `.json` และส่งออกสคริปต์ที่เลือกเป็น `.txt`
- สำรองสคริปต์ทั้งหมดเป็น `.json` ที่ระบุเวอร์ชันรูปแบบข้อมูล เพื่อนำกลับเข้าหรือย้ายเบราว์เซอร์
- จำความเร็ว ขนาดตัวอักษร โหมดกระจก และค่าการอ่านในเบราว์เซอร์เดิม
- เลื่อนอัตโนมัติ ข้ามท่อน สุ่มท่อน วนซ้ำ และแสดงข้อความแบบกระจกสำหรับชุด teleprompter
- โหมดตามเสียงภาษาไทยและหน้าต่างลอยบนเบราว์เซอร์ที่รองรับ พร้อมคู่มือในแอปและหน้าจอที่ปรับตามมือถือ
- คัดกรองคำเสี่ยงในบริบทโฆษณาผลิตภัณฑ์เสริมอาหารด้วยฐานคำของโปรเจกต์

### รูปแบบสคริปต์

ใช้บรรทัดที่ขึ้นต้นด้วย `#` เพื่อแบ่งท่อน และครอบข้อความด้วย `*` เพื่อเน้นสี เช่น:

```text
# 👋 ทักทาย
สวัสดีครับ วันนี้มาคุยเรื่อง *การเตรียมตัวก่อนอัดคลิป*

# 💡 เนื้อหาหลัก
เตรียมประเด็นสั้น ๆ แล้วทดลองอ่านด้วยความเร็วที่สบาย
```

ไฟล์ `.md` ใช้รูปแบบเดียวกันนี้ **ไม่ได้แสดงผล Markdown เต็มรูปแบบ** เช่น ตาราง รูปภาพ หรือลิงก์ หากเปิดสุ่มท่อน แต่ละท่อนควรอ่านแยกกันได้โดยไม่อ้างถึงท่อนก่อนหน้า

### นำเข้าและสำรองข้อมูล

ไฟล์สำรอง JSON ที่สร้างจากแอปรองรับสูงสุด **32 MiB** และเก็บชื่อกับเนื้อหาเดิมครบถ้วน รวมถึงชื่อว่าง ช่องว่าง และฉบับร่าง โดยไม่จำกัดจำนวนรายการภายในขนาดไฟล์นี้ ไฟล์สำรองเก็บเฉพาะสคริปต์ ไม่รวมค่าการอ่านและตำแหน่งที่อ่านค้างไว้

ไฟล์ TXT/MD และ JSON แบบอาร์เรย์รุ่นเก่ารองรับสูงสุด **2 MiB ต่อไฟล์**, **200 สคริปต์ต่อไฟล์**, **500,000 อักขระต่อสคริปต์** และชื่อยาวไม่เกิน **200 อักขระ** ใช้ไฟล์ข้อความ UTF-8 เพื่อให้ภาษาไทยแสดงถูกต้อง หากคลังเกินขีดจำกัดสำรอง 32 MiB ให้ส่งออกสคริปต์เป็น TXT แยกไฟล์ก่อนปิดหน้า

การนำเข้าเพิ่มรายการเข้าในคลังเดิม โดย **คงรายการเดิมไว้** และข้ามรายการที่มีทั้งชื่อและข้อความตรงกัน สคริปต์ที่ใช้ชื่อเดิมแต่เนื้อหาต่างกันจะเก็บเป็นอีกรายการ จึงควรตรวจคลังหลังนำเข้าไฟล์สำรอง

ไฟล์ `.txt` เก็บข้อความของสคริปต์ที่เลือก ส่วน `.json` ใช้สำรองคลังสคริปต์ การย้ายไปเครื่องอื่นทำโดยส่งไฟล์สำรองให้ตัวเองแล้วนำเข้าบนเครื่องปลายทาง

### คีย์ลัดระหว่างอ่าน

| คีย์ | ทำอะไร |
|---|---|
| `Space` | เล่น / พัก |
| `↑` / `↓` | เร็วขึ้น / ช้าลง |
| `←` / `→` | ท่อนก่อน / ท่อนถัดไป |
| `Home` / ปุ่ม ⏫ | กลับขึ้นบนสุด; สับท่อนใหม่เมื่อเปิดการสุ่ม |
| `Esc` | ออกและจำระยะอ่านไว้ |

ปุ่มเสริม: 🎙 ตามเสียง · 🪞 กระจก · 🔲 หน้าต่างลอย (Document Picture-in-Picture) เมื่อเปิดสุ่มท่อน ระยะที่จำไว้จะใกล้เคียงเดิม แต่ข้อความ ณ ตำแหน่งนั้นอาจเปลี่ยน

## ข้อมูลส่วนตัวและข้อจำกัด

**สคริปต์อยู่ใน localStorage ของเบราว์เซอร์และเว็บไซต์ที่ใช้อยู่** ไม่มีบัญชีผู้ใช้ ไม่มีฐานข้อมูลกลาง และไม่ซิงก์ข้ามอุปกรณ์หรือเบราว์เซอร์ การล้างข้อมูลเว็บไซต์ เปลี่ยนโปรไฟล์ หรือปิดหน้าต่างส่วนตัวอาจทำให้ข้อมูลหาย ควรดาวน์โหลดไฟล์สำรองก่อน

ตัวแอปไม่ส่งเนื้อหาสคริปต์ไปเก็บบนเซิร์ฟเวอร์ของแอป แต่โหลดฟอนต์จาก Google Fonts และบริการรู้จำเสียงของเบราว์เซอร์อาจใช้อินเทอร์เน็ตหรือส่งเสียงไปประมวลผลตามผู้ให้บริการ จึงไม่ได้รับประกันว่าทุกฟังก์ชันทำงานออฟไลน์

- การเลื่อนอัตโนมัติเป็นโหมดหลัก โหมดตามเสียงและหน้าต่างลอยขึ้นกับการรองรับของเบราว์เซอร์ โดยแนะนำทดลองบน **Chrome บนคอมพิวเตอร์**
- การใช้ไมโครโฟนต้องอนุญาตสิทธิ์และเปิดจากต้นทางที่ปลอดภัย เช่น HTTPS หรือ `localhost` การรองรับและความแม่นยำของ Web Speech แตกต่างตามเบราว์เซอร์ สำเนียง เสียงรบกวน และการเชื่อมต่อ
- หน้าต่างลอยต้องมี Document Picture-in-Picture และไม่รับประกันการใช้งานบนมือถือหรือทุกเบราว์เซอร์
- ผลตรวจคำเป็นเพียง **การคัดกรองด้วยการจับคู่ข้อความ** อาจตรวจไม่พบคำหรือบริบทเสี่ยง และไม่ใช่การรับรองว่าถูกกฎหมายหรือผ่านนโยบายแพลตฟอร์ม
- ราคา โปรโมชั่น และเนื้อหาสินค้าในสคริปต์ Fuxian เป็นตัวอย่างที่เก็บจากการจัดทำคลังเดิม ผู้ใช้ต้องตรวจฉลาก ราคาปัจจุบัน และข้อกำหนดที่เกี่ยวข้องก่อนนำไปใช้จริง

## ใช้จากไฟล์ที่ดาวน์โหลด

แตก ZIP แล้วเปิด Terminal ในโฟลเดอร์ที่มี `index.html` จากนั้นรันด้วย Python 3:

```bash
python3 -m http.server 8231 --bind 127.0.0.1
```

เปิด [http://localhost:8231](http://localhost:8231) ในเบราว์เซอร์ ใช้ `Ctrl+C` ใน Terminal เพื่อหยุดเซิร์ฟเวอร์ ไม่ต้องติดตั้ง Node.js หรือ npm เพื่อใช้งานแอปตามวิธีนี้ ข้อมูลบน `localhost` จะแยกจากข้อมูลบนเว็บออนไลน์

### แผนที่โค้ดใน index.html (ไล่ตาม comment `/* ===== */`)

| ส่วน | ทำอะไร |
|---|---|
| `scripts storage` | localStorage `fx_scripts` = `[{id,name,text,pos}]`, `fx_cur` = id ที่เลือก, `fx_settings_v1` = ค่าการอ่าน, `pos` = scrollTop ที่จำไว้ตอนออก · ตรวจรูปแบบข้อมูลตอนโหลดและถอยกลับไป seed หากข้อมูลเสีย · เขียนไม่ได้จะแจ้งด้วย toast |
| `SEED3` + migration | สคริปต์ตัวอย่าง "Multi-Oil LIVE 100 ท่อน" · ระบบ sync ผ่าน `fx_seed_v` (ตอนนี้ `'8'`) — **แก้สคริปต์ seed = แก้ SEED3 แล้ว bump เลขเวอร์ชันทั้ง 2 จุด** ระบบตรวจชื่อและ fingerprint ของ seed v5–v7 ก่อนย้าย/ยุบชุดเสริมเก่า จึงไม่ทับสคริปต์ที่ผู้ใช้เปลี่ยนเนื้อหาหรือตั้งชื่อขึ้นต้นคล้ายกัน |
| `ตัวตรวจคำเสี่ยง` | สแกน `FX_KEYWORDS` แบบ substring (lowercase) ทุกครั้งที่พิมพ์ (debounce 400ms) · `KW_WHITELIST` = วลี disclaimer บังคับที่มีคำอย่าง "รักษาโรค" อยู่ข้างใน — ตัดออกก่อนสแกน ไม่นับเป็นคำผิด |
| `tokenize / matchPos` | ตัดคำไทยด้วย `Intl.Segmenter('th')` · matcher โหมดตามเสียงเป็น windowed scan (cur-10..cur+80) ต้องตรง ≥2 คำถึงขยับ · เริ่มจากคำใกล้เส้นโฟกัสและขึ้นรอบใหม่หลังคำสุดท้าย |
| `roundText()` | หัวใจระบบสุ่ม: แตก text เป็น block ตามบรรทัดขึ้นต้น `#` → ถ้าเปิดการสุ่มและมี ≥2 ท่อน สับลำดับทั้งหมด (Fisher-Yates) ทุกรอบ + กันเปิดรอบด้วยท่อนเดิมซ้ำ; ปิดการสุ่มแล้วรักษาลำดับเดิม |
| `buildPrompt()` | สร้าง DOM: `#` → `.sec` (หัวทอง) · `*คำ*` → span `.hl` (เหลืองหนา, เครื่องหมาย * ไม่แสดง, ส่วนที่ไม่ใช่คำเช่น `,` ใน `1,290` ก็ต้องเหลือง) · ทุกคำเป็น span คลิกได้เฉพาะโหมดตามเสียง |
| `loop (step/raf)` | เลื่อนด้วย `scrollTop += speed*dt` — dt จากเวลาจริง · rAF + `setInterval(step,250)` สำรอง (rAF หยุดตอนแท็บ hidden) · `holdUntil`: ผู้ใช้ปัด/หมุนลูกกลิ้ง = พัก loop 1.5 วิ ไม่สู้กับนิ้ว · ถึงก้นจอเมื่อเปิดวนซ้ำ = `buildPrompt()` รอบใหม่ + พัก 2 วิ; ปิดวนซ้ำแล้วหยุดเมื่อจบ |
| `setVoice()` | สร้าง SpeechRecognition ใหม่ต้อง `stopRec()` ตัวเก่าก่อนเสมอ (กัน recognizer ซ้อน) · error ≥3 ครั้ง หรือ not-allowed → ถอยไปโหมดเลื่อนเองอัตโนมัติ + toast (ห้ามใช้ alert — modal จะ freeze ตัวเลื่อน) |
| `openPip()` | Document Picture-in-Picture: ย้าย `#scroller` ไปอีก document → **ต้องใช้ตัวแปร `scrollerEl/ptextEl` ที่จับไว้ตอนโหลด ห้าม getElementById สด** (จะได้ null หลังย้าย) · ต้องหยุด rAF ของ window เดิมก่อนสลับ `scrollWin` · mirror ติดกับ scroller เพื่อย้ายตามไป PiP |
| `enterPrompt/exitPrompt` | generation token `gen` กัน countdown ค้างแล้วกลับมาสตาร์ทหลังกดออก · โหมดเสียงขอไมค์**ก่อน**นับถอยหลัง · ออก = เซฟ `pos` และปิด PiP · เมื่อเปิดสุ่มท่อน การเข้ารอบใหม่ทำให้ `pos` เป็นระยะใกล้เคียง ไม่รับประกันว่าเป็นข้อความเดิม |

### กับดักที่เคยพังมาแล้ว (อย่าทำซ้ำ)

1. **ห้ามใส่ `scroll-behavior:smooth`** บน `#scroller` และห้ามใช้ `scrollTo({behavior:'smooth'})` ขณะ loop เดิน — instant scroll ของ loop จะ cancel smooth ทิ้งกลางทาง ทำให้ปุ่มข้ามท่อน "ดูเหมือนตาย" → กระโดดด้วย `scrollTop =` ตรงๆ เท่านั้น
2. **PiP กับ element refs/rAF owner** — ตามตารางข้างบน เคยทำ auto-scroll ตายทั้งจอมาแล้ว · เรียก `stopLoop()` กับ window เดิมก่อนเปลี่ยน `scrollWin` เสมอ
3. **ห้าม `alert()`** ในโหมดอ่าน — ใช้ `toast()` เท่านั้น
4. **แตะจอเรียกแถบปุ่มกลับมา ≠ คลิกคำ** — มี `swallowClickUntil` กันไว้ อย่าลบ

### กติกาเนื้อหา seed Fuxian (เจ้าของโปรเจคสั่งไว้ชัด — ห้ามฝ่าฝืน)

กติกาต่อไปนี้ใช้กับคลังตัวอย่าง Fuxian ที่มากับแอป ไม่ได้บังคับสคริปต์ส่วนตัวทุกประเภทของผู้ใช้

- ท่อนสคริปต์เป็น**อิสระต่อกัน ไม่ต่อเนื่อง** รวม 100 ท่อน ระบบสุ่มวนเอง
- เรียกลูกค้า **"แม่ / แม่ๆ / แม่ขา"** เรียกตัวเอง **"น้อง"**
- **ตัวเลขเป็นเลขอารบิกเสมอ**: `490 บาท` `1,290 บาท` `2 แถม 1` `30 ซอฟต์เจล` — ห้ามเขียนคำอ่าน (สี่ร้อยเก้าสิบ ✗)
- **emoji นำหน้าทุกบรรทัด** · `*คำสำคัญ*` ครอบชื่อสินค้า/ราคา/โปร/CF
- **ห้ามคำต้องห้าม TikTok/อย.** — เช็คกับ `keywords.js` เสมอ (ลดน้ำหนัก/ผอม/เบิร์น/รักษา/ที่สุด ✗ → ดูแลรูปร่าง/คุมอาหาร ✓) ยกเว้นวลี disclaimer บังคับ "ผลิตภัณฑ์เสริมอาหาร ไม่ใช่ยา ไม่มีผลป้องกันหรือรักษาโรค" ที่**ต้องมี**ในคลัง
- ราคาตัวอย่างที่ใช้ใน seed จากการจัดทำคลังเดิม (ไม่ใช่การยืนยันราคาปัจจุบัน): 1 กระปุก 490 บาท · 2 แถม 1 = 1,290 บาท (เฉลี่ย 430 บาทต่อกระปุก)
- **วิธีรับประทานต้องยึดตามฉลาก** — ห้ามเดาจำนวนเม็ดหรือช่วงเวลา หากข้อมูลสาธารณะยังยืนยันไม่ได้
- **ไม่มีรีโมทมือถือ** — เคยมี (PeerJS) แล้วเจ้าของสั่งถอดออก อย่าเสนอ/ใส่กลับ

### keywords.js

`window.FX_KEYWORDS = [{term, level:'ban'|'risky', reason, safe?}]` + `FX_KEYWORD_NOTES` (กติกาที่ไม่ใช่คำ เช่น ห้ามภาพ Before/After)
ที่มาที่ระบุไว้ในการจัดทำฐานคำเดิม (ต้องตรวจฉบับปัจจุบันก่อนอ้างความสอดคล้อง): บัญชีแนบท้ายประกาศ อย. เรื่องหลักเกณฑ์โฆษณาอาหาร พ.ศ. 2564 (กลุ่ม 1, 2.1–2.5) + ม.40/41 พ.ร.บ.อาหาร + นโยบาย TikTok Shop ไทย
เพิ่มคำใหม่: เลือก term ให้เฉพาะเจาะจงพอที่ substring match จะไม่จับคำปกติมั่ว (เช่น ใช้ `สุดยอด` ไม่ใช่ `ยอด`)

### ทดสอบอัตโนมัติและด้วยมือหลังแก้

ใช้ **Node.js 22+** สำหรับการทดสอบ และต้องมี **Python 3 กับ Chrome/Chromium** เพิ่มสำหรับ browser test ไม่มี dependency จึงรันได้โดยไม่ต้อง `npm install`

```bash
npm run test:unit
npm run test:browser
# หรือรันครบทุกชุด
npm test
```

`test:unit` รัน `tests/seed-content.test.mjs` และ `tests/script-transfer.test.mjs` ส่วน `test:browser` รัน `tests/browser-seed-regression.mjs` โดยเปิด local server และโปรไฟล์ Chrome แยกสำหรับทดสอบ หากตรวจหาเบราว์เซอร์ไม่พบ ให้กำหนด `CHROME_PATH` เป็น path ของ executable เช่น:

```bash
CHROME_PATH="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" npm run test:browser
```

GitHub Actions รัน `npm test` บน Ubuntu พร้อม Node.js 22, Python 3 และ Chrome ที่มีใน runner ดูผลได้ที่ [Actions](https://github.com/gobank01/fuxian-teleprompter/actions)

1. unit test ต้องผ่านการตรวจ seed 100 ท่อน คำเสี่ยง syntax และการนำเข้า/สำรอง/รวมข้อมูล
2. browser test ต้องผ่าน migration, 100 ท่อน, คำเสี่ยง, การสุ่ม และการรักษาสคริปต์ผู้ใช้
3. โหลดหน้า → สคริปต์ "Multi-Oil LIVE 100 ท่อน" ขึ้น + ตัวตรวจขึ้น "✅ ไม่พบคำเสี่ยง"
4. พิมพ์ "ลดน้ำหนัก" ในสคริปต์ → ต้องขึ้น 🔴 พร้อมคำแทน แล้วลบ → กลับเป็น ✅
5. เปิดสุ่มท่อนและวนซ้ำ แล้วเริ่มอ่าน → เลื่อนเอง, กด ⏭ ขณะเล่นต้องกระโดดทันที, ลาก scrollTop ไปก้นจอ → ต้องเด้งขึ้นรอบใหม่เองภายใน ~2 วิ พร้อมลำดับท่อนใหม่
6. Esc → กลับหน้าแก้ไข → เริ่มใหม่ → ต้องกลับมาที่ระยะใกล้เคียงเดิม (ข้อความอาจเปลี่ยนเพราะสับท่อนใหม่)
7. เปิดวนซ้ำแล้วใช้โหมดตามเสียง → เลื่อนไปกลางสคริปต์ก่อนเปิดโหมด → matcher ต้องเริ่มใกล้ viewport และเมื่ออ่านถึงคำสุดท้ายต้องขึ้นรอบใหม่ภายใน ~2 วิ
8. เปิดหน้าต่างลอย → auto-scroll ต้องเดินต่อ, กระจกต้องยังทำงาน, กด Esc แล้วหน้าต่างลอยต้องปิด
9. ทดลองนำเข้า `.txt` / `.md` / `.json` → ส่งออก `.txt` และสำรอง `.json` → นำไฟล์สำรองกลับเข้า ต้องไม่เพิ่มรายการที่ชื่อและข้อความซ้ำ และต้องคงรายการเดิม
10. เปลี่ยนค่าการอ่านแล้วรีโหลด → ค่ายังคงอยู่; ปิดสุ่มต้องอ่านตามลำดับ และปิดวนซ้ำต้องหยุดเมื่อจบ
11. ทดสอบหน้าจอมือถือ คู่มือในแอป สถานะบันทึก และข้อความแจ้งเตือนเมื่อพื้นที่จัดเก็บเขียนไม่ได้
